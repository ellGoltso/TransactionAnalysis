# Проект TransactionAnalysisProject

## Описание:

TransactionAnalysisProject - это проект для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.

## Установка:

Клонируйте репозиторий:
```
git clone https://github.com/ellGoltso/TransactionAnalysis.git 
```

## Использование:

Пример работы функции get_json_data:

Принимает на вход строку с датой и временем в формате YYYY-MM-DD HH:MM:SS и возвращающую JSON-ответ со следующими данными:

1. Приветствие в формате "???", где ??? — «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» в зависимости от текущего времени.
2. По каждой карте:
   1. последние 4 цифры карты;
   2. общая сумма расходов; 
   3. кешбэк (1 рубль на каждые 100 рублей).
3. Топ-5 транзакций по сумме платежа.
4. Курс валют.
5. Стоимость акций из S&P500.

Поиск переводов физическим лицам:

Функция get_json_transfers_data возвращает JSON со всеми транзакциями, которые относятся к переводам физлицам.

Траты по категории:

Функция принимает на вход:

1. датафрейм с транзакциями,
2. название категории,
3. опциональную дату. Если дата не передана, то берется текущая дата.

Функция возвращает траты по заданной категории за последние три месяца (от переданной даты).

Декоратор write_to_file записывает данные, возвращаемые функцией в указанный файл JSON, если файл не указан записывает в файл: "data/function_results.json"
